# Creative acquisition portfolio

The campaigns below are ranked by how directly they create qualified product
usage. They are not generic social-media “awareness” plays.

## 1. The 100 Drawings Without BIM Project — launch first

**Mechanism:** turn 100 permissioned legacy sheets into private models and
publish only consented, redacted technical cases.

**Why people participate:** they receive useful project work, not a coupon.

**Growth loop:** nomination → private Build Sheet → internal sharing → guided
review → building-scope pilot → optional public case → next nomination.

**Cost posture:** no paid media; cap at five concurrent pilots.

**Ready asset:** `100_DRAWINGS.md`.

## 2. The BIM Receipt — product-led trust loop

**Mechanism:** every conversion generates a machine-readable and human-readable
receipt containing source hash, exact model hashes, entity counts, runtime,
qualification, artifact hashes, and unresolved review categories.

**Why it is unusual:** most conversion marketing distributes a render. Dajoong
distributes an audit artifact that a BIM lead can attach to a handoff or review.

**Growth loop:** recipient opens receipt → inspects a permitted preview → joins
the project review → creates another conversion.

**Build required before launch:** signed public/private receipt URLs, revocation,
access control, safe metadata schema, and project invitation. The current Build
Sheet schema is ready; public sharing is not yet authorized.

## 3. Drawing Debt Audit — account-based lead magnet

**Mechanism:** an organization submits an inventory, not drawings: building
count, floor count, source formats, age, known scale, update frequency, and
downstream use. Dajoong returns a “drawing debt” map showing which assets are
ready for conversion, which need scale recovery, and which require survey work.

**Why it works:** the result scopes an actual portfolio program without asking a
facility team to upload confidential documents during first contact.

**Growth loop:** inventory → prioritized sample → one private conversion →
portfolio proposal.

**Build required:** a short calculator and downloadable PDF/CSV report. Do not
invent savings; show workload bands and unresolved information only.

## 4. What the Compiler Refused to Guess — technical media series

**Mechanism:** publish one difficult ambiguity each week: an unresolved door
operation, contradictory scale, broken enclosure, impossible stair connection,
or unmeasured benchmark claim. Show why release was blocked and how Studio
resolved it.

**Why it is distinctive:** professional buyers see safety judgment and model
governance instead of another AI highlight reel.

**Growth loop:** technical explanation → challenge nomination → private pilot →
permissioned case.

**Ready asset:** weekly template in `content/LAUNCH_COPY.md`.

## 5. Consultant Co-Delivery Network — distribution moat

**Mechanism:** BIM consultants use Dajoong for the evidence-linked first pass and
retain client ownership and final acceptance. Dajoong measures correction types
and improves workflow without silently training on client files.

**Why it is difficult to copy:** the relationship combines software, reviewer
workflow, permissioned evidence, and correction history. It is not merely an
affiliate fee.

**Growth loop:** consultant nominates one difficult plan → co-review → repeatable
building delivery → integration and seat expansion.

**Ready asset:** partner sequence in `outreach/OUTREACH_SEQUENCE.md`.

## Channel order

1. Founder and first-degree professional network
2. Five BIM consultant design partners
3. Permissioned case pages and technical search content
4. buildingSMART chapter/community participation
5. Autodesk Design and Make Marketplace listing
6. Carefully targeted paid search only after organic funnel validation

Do not start with broad Meta/TikTok ads. They are likely to attract residential
rendering demand and consume review capacity without testing the B2B wedge.

## Budget choices

### Recommended: validation — $0 media

- 20 private slots
- founder distribution
- five consultant invitations
- manual guided reviews
- objective: prove qualified demand and support cost

### Evidence production — up to $500, separately approved

- professional editing/captioning for three consented technical cases
- no boosted posts
- objective: improve case clarity, not manufacture reach

### Scaled acquisition — up to $2,500, only after thresholds pass

- intent search around plan-to-IFC, legacy BIM, and existing-building modeling
- retargeting remains off unless privacy consent and audience size justify it
- stop automatically when qualified nomination cost exceeds the approved limit

The package intentionally does not forecast revenue or CAC before the first
cohort produces actual conversion, review, and sales data.
